# React Conditional Render App

A small React + Vite demo of conditional rendering. A button toggles a login state, and the page shows either "Welcome back!" or "Please log in."

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run preview` – preview the production build
- `npm run lint` – run ESLint

## What you will learn

- Store a login flag with `useState`.
- Render different text and button labels based on a condition.
- Update the page in response to a click event.

## Follow the code

In `src/App.jsx`, find `isLoggedIn`, its click handler, and the two conditional messages.
