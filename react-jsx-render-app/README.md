# React JSX Rendering Practical

A small React example showing how JSX can combine HTML-like tags with JavaScript values.

## What you will learn

- How JSX describes the interface React should render.
- How to insert JavaScript variables with curly braces.
- How to create a JSX value and use it inside another element.

## Follow the code

In `src/main.jsx`, `name` and `age` are inserted into a JSX message. The message is then included in the page passed to `createRoot`.

## Run it

Requirements: Node.js and npm. In this folder run `npm install`, then `npm run dev`, and open the local address shown by Vite.

## Try this next

Change the values, then add a `Student` component that receives `name` and `age` as props.
