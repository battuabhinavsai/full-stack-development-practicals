# React HTML Rendering Practical

A minimal React example that mounts a page into the browser. It introduces the entry point before adding components, props, or state.

## What you will learn

- How `createRoot` connects React to the `root` element in `index.html`.
- How React renders elements written with JSX.
- How the browser page is assembled from nested elements.

## Follow the code

Open `src/main.jsx`: it selects the `root` element and renders a heading and paragraph inside a `div`. `index.html` provides the mount point.

## Run it

Requirements: Node.js and npm. In this folder run `npm install`, then `npm run dev`, and open the local address shown by Vite.

## Try this next

Add another section with a heading and list. Then move the rendered content into an `App` component.
